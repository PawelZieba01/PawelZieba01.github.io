[002] Embedded Linux with Yocto Project - Master Thesis

Paweł Zięba September 10, 2026

Current project · Master's Thesis · Work in Progress

This project is being developed as my Master's Thesis at AGH University of Krakow and is a direct continuation of my Engineering Thesis focused on Linux kernel device drivers.

While the previous project explored the interface between the Linux kernel and external hardware through custom I²C and SPI device drivers, the current work moves one level higher: towards building a complete and reproducible Embedded Linux system using the Yocto Project.

Project Overview

The main goal of the project is to explore the complete process of creating a customized Linux system for an embedded target using Yocto Project, Poky and BitBake.

Instead of relying on a general-purpose Linux distribution, the system is built specifically for the target platform. This makes it possible to control the system configuration, installed packages, services, hardware support and application software directly from the build system.

The work covers the progression from a minimal Linux image to a customized embedded distribution, including the creation of custom Yocto layers, image recipes, distribution configuration and integration of platform-specific functionality.

Current Development

The project is currently under active development. The current work focuses on building and understanding the Yocto-based environment and gradually moving system configuration from local build settings into reusable metadata.

Current areas of work include:

  • building minimal Embedded Linux images with Yocto,
  • configuring the build environment using Poky and BitBake,
  • integrating the Raspberry Pi BSP through meta-raspberrypi,
  • developing a custom Yocto layer,
  • creating a custom Linux image and distribution configuration,
  • configuring system services and platform-specific features,
  • working with systemd, SSH, Wi-Fi and UART,
  • preparing the system for integration with custom kernel drivers and user-space software.

From Kernel Driver to Complete Embedded Linux System

One of the main ideas behind this project is to extend the work completed during my Engineering Thesis.

That project focused on developing Linux kernel drivers for external devices connected through I²C and SPI. The Master's Thesis expands this concept by placing those low-level components inside a complete Embedded Linux environment built specifically for the target hardware.

The planned system combines the operating system image, Linux kernel drivers and a user-space application into a single embedded platform. Ultimately, this creates a complete path from physical hardware, through the Linux kernel, to application-level control.

Target System Architecture

The diagram below presents a simplified concept of the target system. A Raspberry Pi Zero W runs a custom Linux image containing kernel drivers responsible for communication with external devices over the I²C and SPI buses. A user-space application communicates with the hardware through standard Linux interfaces exposed by the kernel.

The architecture is intentionally based on the device-driver work developed during my Engineering Thesis. External peripherals such as I/O expanders, EEPROM memories and a DAC provide a practical hardware platform for integrating and testing the complete software stack.

User-Space Application

As a later stage of the project, a user-space application is planned to provide a convenient interface for interacting with selected hardware functions exposed by the system.

The interface shown below is an early graphical concept rather than the final implementation. It illustrates one possible way of controlling digital outputs and a DAC while presenting basic device and system status.

The application is not the primary focus of the thesis. Its role is to demonstrate the complete integration path between the application layer, Linux interfaces, custom kernel drivers and physical hardware.

Development Environment

  • Build system: Yocto Project / Poky / BitBake
  • Target platform: Raspberry Pi
  • Target hardware: Raspberry Pi Zero W
  • BSP: meta-raspberrypi
  • Custom layer: meta-asicsagh
  • Init system: systemd
  • Hardware interfaces: I²C, SPI, UART
  • Connectivity: Wi-Fi / SSH
  • Host environment: Rocky Linux
  • Build environment: Docker

Planned Final Result

The planned final result is a customized Embedded Linux system containing the required operating-system configuration, kernel drivers and user-space software for the target platform.

The project is intended to demonstrate the complete embedded software stack:

Hardware → I²C / SPI → Linux Kernel Drivers → Embedded Linux → User Space → Application

In this way, the Master's Thesis extends the low-level driver development explored in my Engineering Thesis into the broader process of designing, configuring and integrating a complete Linux-based embedded system.

Project Status

This project is currently in development.

It is the main technical project I am currently working on as part of my Master's Thesis at AGH University of Krakow. Because the thesis is still being developed, the source repository and complete technical documentation are not publicly available at this stage.

This page presents the current scope, architecture and direction of the project. It will be updated as development progresses and additional parts of the project can be presented publicly.
