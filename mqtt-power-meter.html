[004] MQTT Power Meter

Paweł Zięba September 10, 2026

IoT energy monitoring system based on ESP32-C3, MQTT and Home Assistant

MQTT Power Meter is a compact IoT device designed to monitor household electricity consumption in real time. The project combines embedded software, electronics, MQTT communication, home automation and 3D design into a complete working system.

The device reads light pulses generated by the LED built into an electricity meter, processes them using an ESP32-C3 and sends the collected data to a Home Assistant server via MQTT. The measurements can then be stored and visualized, providing both real-time and historical insight into energy consumption.

From Meter Pulses to Useful Data

Many modern electricity meters indicate energy consumption using an integrated LED, where each pulse represents a defined amount of consumed energy.

MQTT Power Meter uses a light sensor mounted directly over this LED. The ESP32-C3 detects and counts the pulses and periodically transmits the measurements over WiFi using MQTT.

The collected data is integrated with Home Assistant and can be stored in InfluxDB and visualized using Grafana.

This creates a simple monitoring chain:

Electricity Meter → Light Sensor → ESP32-C3 → WiFi / MQTT → Home Assistant → InfluxDB → Grafana

Hardware

The device is built around an ESP32-C3 SuperMini combined with an LDR light sensor module based on the LM393 comparator.

The ESP32-C3 was selected because its compact form factor, WiFi connectivity and low power consumption make it well suited for small IoT devices.

The light sensor detects the flashes generated by the electricity meter without requiring any electrical connection to the meter itself.

Custom Enclosure

A dedicated enclosure was designed for the device and manufactured using 3D printing.

The enclosure holds both the ESP32-C3 and the light sensor while providing access to the USB connector, sensor LEDs and sensitivity adjustment potentiometer. It was also designed to allow simple installation and removal from the electricity meter.

Software

The embedded software was developed using ESP-IDF and divided into separate modules responsible for WiFi connectivity, MQTT communication, OTA updates and pulse detection.

The device supports Over-the-Air firmware updates, allowing new software versions to be installed remotely without physical access to the ESP32.

Since the device is intended to operate continuously near the electricity meter, the software also includes mechanisms for recovering from connectivity problems and automatically reconnecting to the network.

Home Assistant and Data Visualization

Measurement data is transmitted using MQTT to a Home Assistant server running on a Fujitsu Futro S920.

The system integrates:

  • Home Assistant
  • Mosquitto MQTT Broker
  • InfluxDB
  • Grafana
  • Cloudflare remote access
  • Google Drive backups

Grafana provides a convenient way to visualize both current and historical electricity consumption.

Testing

The system was tested during continuous operation on a real electricity meter.

During one of the long-term tests, the device operated for 24 days and recorded approximately 108 kWh of energy consumption, while the electricity meter registered 108.9 kWh over the same period.

This confirmed that the complete measurement and communication chain could operate reliably over an extended period.

Technologies

ESP32-C3 ESP-IDF C FreeRTOS WiFi MQTT OTA Home Assistant Mosquitto InfluxDB Grafana Cloudflare 3D Printing
