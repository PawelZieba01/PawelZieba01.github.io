[014] ESP8266 Smart Utility Meters

Paweł Zięba September 10, 2026

Water and gas consumption monitoring integrated with Home Assistant

This project consists of two closely related IoT devices designed to monitor household water and gas consumption and integrate the collected measurements with a Smart Home environment.

Both devices are based on the ESP8266 and follow the same general concept: detect physical events generated by an existing utility meter, count them using a microcontroller and make the resulting consumption data available in Home Assistant.

The main difference between the two implementations is the method used to acquire measurements from the physical meter.

Gas Meter → Pulse Sensor → ESP8266 → WiFi → Home Assistant

Water Meter → Inductive Sensor → ESP8266 → WiFi → Home Assistant

Gas Meter Monitoring

The first version of the system was developed for monitoring household gas consumption.

A dedicated pulse sensor mounted directly on the gas meter detects events generated by the mechanical meter. Each detected pulse represents a defined amount of consumed gas.

The ESP8266 counts these pulses and uses them to determine gas consumption before transferring the collected information to the Smart Home system.

This approach makes it possible to add remote consumption monitoring to an existing gas meter without modifying its internal mechanism.

The external sensor acts as the interface between the traditional meter and the digital monitoring system.

Water Meter Monitoring

The second implementation uses the same general concept but adapts it to a household water meter.

Instead of using a dedicated pulse output, the system uses an inductive proximity sensor mounted next to the meter.

The sensor detects the movement of a metal element rotating inside the water meter. Each detected pass of the metal element generates an event that can be counted by the ESP8266 and converted into water consumption.

This solution provides contactless detection of the meter movement and does not require electrical modification of the water meter itself.

ESP8266 Controller

Both devices use an ESP8266 as the main processing and communication unit.

The microcontroller receives signals from the connected sensor, counts measurement events and uses its integrated WiFi connectivity to communicate with the Smart Home environment.

Using the same microcontroller platform for both devices allowed the overall architecture to remain very similar while only the physical measurement interface had to be adapted to the specific type of utility meter.

Home Assistant Integration

The collected measurements are integrated with Home Assistant, allowing water and gas consumption to become part of the existing Smart Home system.

This makes it possible to monitor household utility usage together with other connected devices and environmental measurements from a single interface.

Historical measurements can also be used to observe consumption trends and compare utility usage over longer periods of time.

One Platform – Two Measurement Methods

Although both devices perform a similar task, they demonstrate two different approaches to obtaining information from existing utility meters.

Project Approach

An important goal of both projects was to extend the functionality of conventional utility meters without replacing or internally modifying them.

The existing meters remain responsible for the actual measurement, while an external sensor allows the ESP8266 to observe their operation and transfer the information into the Smart Home environment.

The result is a simple IoT layer added on top of traditional household infrastructure.
