Linux Device Drivers – Engineering Thesis

Practical introduction to Linux device driver development using SPI and I²C devices

This project was developed as part of my Engineering Thesis at AGH University of Krakow. Its main goal was to explore Linux kernel mechanisms used for hardware communication and to implement practical device drivers for external peripherals.

The project combines low-level programming in C with hands-on hardware development on a Raspberry Pi platform.

About the project

The work started with the fundamentals of Linux Kernel Modules (LKM) and gradually moved towards complete device drivers communicating with real hardware.

As part of the project, I implemented and explored:

  • Linux Kernel Modules and their lifecycle
  • Character device drivers and communication between userspace and kernel space
  • Device Tree and hardware description
  • Platform devices and platform drivers
  • SPI device drivers
  • I²C device drivers
  • REGMAP API
  • Hardware control directly from the Linux kernel

The individual stages of development were separated into dedicated Git branches, making it possible to follow the project from basic kernel modules to more advanced hardware drivers.

SPI

As part of the SPI section, I implemented drivers for external peripheral devices, including the MCP4921/MCP4922 digital-to-analog converter (DAC).

The project covers communication between the Linux kernel and SPI devices as well as the integration of hardware peripherals with the Linux device model.

I also explored communication with an I/O port expander using the Linux kernel REGMAP API.

I²C

The project also includes implementations of drivers for external integrated circuits communicating over the I²C bus.

This part allowed me to explore how the Linux kernel handles I²C devices and how hardware described through Device Tree can be matched with the appropriate kernel driver.

Platform Devices

In addition to SPI and I²C devices, I implemented practical examples based on Linux platform devices.

These included drivers used to control hardware such as:

  • LEDs
  • servo motors

This provided practical experience with the Linux device model and communication between kernel-space software and physical hardware.

Technologies

Programming: C
Operating System: Linux, Kernel 6.1
Platform: Raspberry Pi
Kernel: Linux Kernel Modules, Device Drivers
Hardware Description: Device Tree
Interfaces: SPI, I²C
Linux APIs: REGMAP, Platform Devices

What I learned

The project gave me practical experience with Linux development at kernel level and helped me understand how the operating system communicates with hardware.

It also allowed me to combine my electronics background with software development by working directly with physical peripherals connected through SPI and I²C.

The project became the foundation for my further development in Embedded Linux, Yocto and SoC-based systems.
