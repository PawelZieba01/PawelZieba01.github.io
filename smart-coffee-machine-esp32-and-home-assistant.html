[015] Smart Coffee Machine – ESP32 & Home Assistant

Paweł Zięba August 31, 2026

This project is a custom ESP32-based controller that integrates a Braun Tassimo coffee machine with Home Assistant.

The goal was to add remote control and automation capabilities to a standard coffee machine using an external embedded system.

The controller is based on an ESP32, and the application is written in MicroPython.

The Idea

The original coffee machine does not provide a network interface that could be directly integrated with a home automation system.

To determine the current state of the machine, the ESP32 monitors the LEDs located on its original control panel.

Based on these signals, the controller can determine what the coffee machine is currently doing and react accordingly.

This approach made it possible to add network connectivity and Home Assistant integration without replacing the original control electronics.

 

Coffee Machine State Detection

One of the key parts of the project is detecting the current state of the coffee machine.

Instead of using an internal communication protocol, the ESP32 monitors signals controlling the LEDs on the machine's original user interface.

These signals provide information about the current operating state and allow the external controller to react to changes during the brewing process.

Home Assistant Integration

The ESP32 communicates over the local network and integrates the coffee machine with a Home Assistant server.

The system provides several additional features:

• Remote coffee brewing activation over LAN
• Control through Home Assistant
• Scheduled coffee brewing
• Notification when the brewing process is complete
• Protection against starting another brewing cycle using the same capsule

This turns a conventional coffee machine into an IoT device that can be controlled and monitored as part of a home automation system.

Multithreaded Software

The MicroPython application uses two system threads operating simultaneously.

One thread is responsible for network communication, while the second handles interaction with the coffee machine and monitors its current state.

This separates network-related tasks from hardware interaction.

WebREPL

The project also supports WebREPL, allowing remote access to the ESP32 over the network.

This makes it possible to communicate with and program the controller without requiring a direct physical connection to the microcontroller.

Technologies

Microcontroller: ESP32
Programming language: MicroPython
Home automation: Home Assistant
Communication: LAN / WiFi
Remote access: WebREPL
Architecture: Multithreaded application
Application: IoT / Home Automation

What I Learned

This project gave me practical experience in integrating an existing electronic device with an external embedded controller and a home automation system.

The main challenge was to understand the behavior of the original hardware and use the available signals to determine the current state of the coffee machine.

The project also provided practical experience with ESP32, MicroPython, network communication, multithreaded applications, hardware signal monitoring, remote device access, and Home Assistant integration.
