[020] Smart Beehive Scale

Paweł Zięba August 31, 2026

 

The Smart Beehive Scale is an IoT project designed to remotely monitor basic parameters of a beehive.

The system is based on an ESP32/ESP8266 microcontroller and collects information about beehive weight, ambient temperature, and air humidity.

The project was developed in MicroPython and combines several sensors, local data storage, and GSM communication in a single embedded system.

Project status: Work in Progress

The Idea

Changes in beehive weight can provide valuable information about what is happening inside the hive. Combined with temperature and humidity measurements, this creates a simple monitoring system that can collect useful information without requiring constant physical access to the beehive.

The goal of the project was to create a standalone device capable of collecting these measurements directly at the hive, storing them locally, and providing remote communication.

Weight Measurement

The weight measurement system is based on a load cell connected to an HX711 module.

The HX711 provides an interface between the strain gauge load cell and the ESP32/ESP8266 microcontroller.

As part of the project, I developed a dedicated MicroPython module responsible for communication with the HX711 and acquisition of weight measurements.

Temperature and Humidity

Environmental conditions are monitored using a DHT11 sensor.

The sensor provides measurements of:

• ambient temperature
• relative air humidity

A dedicated MicroPython module was created to handle communication with the sensor and acquisition of environmental data.

Local Data Storage

The system includes an SD card reader for local measurement storage.

I developed a dedicated MicroPython module for SD card handling, allowing measurement data to be stored directly by the embedded device.

This provides local data storage independently of the external communication system.

GSM Communication

Remote communication is provided by a SIM800L GSM module.

A dedicated MicroPython module was developed to handle communication between the ESP32/ESP8266 and the GSM modem.

The use of GSM communication makes the concept suitable for locations where a traditional WiFi network may not be available.

Modular Software Architecture

The software was divided into separate modules responsible for individual hardware components.

Dedicated modules were created for:

• HX711 load cell interface
• DHT11 temperature and humidity sensor
• SD card storage
• SIM800L GSM communication

This approach separates hardware-specific functionality from the main application logic and makes individual parts of the system easier to develop and test.

Technologies

Platform: ESP32 / ESP8266
Programming language: MicroPython
Weight measurement: Load cell + HX711
Environmental sensor: DHT11
Local storage: SD card
Communication: SIM800L / GSM
Application: IoT, remote monitoring

What I Learned

The project allowed me to combine several different hardware interfaces into a single embedded system and develop dedicated MicroPython modules for external peripherals.

It also gave me practical experience with sensor data acquisition, load cell measurements, local data storage, GSM communication, and modular embedded software development.

The project is still under development, with the individual hardware modules forming the foundation for the complete beehive monitoring system.
